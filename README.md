# -Iris-Flower-Statistical-Analysis-Python-
Python-based Iris dataset analysis project performing EDA, IQR-based outlier detection, and feature engineering. Implements recursion, functional programming (filter, map, reduce), bitwise encoding, and set operations. Generates an automated, detailed statistical report.

# 🌸 Iris Flower Statistical Analysis

## 📌 Overview

This project performs a comprehensive statistical analysis of the Iris dataset using Python. It includes data exploration, outlier detection, feature engineering, and automated report generation.

---

## 🚀 Features

* 📊 Exploratory Data Analysis (EDA)
* 📈 Statistical summary using Pandas
* 🚨 Outlier detection using IQR method
* 🧮 Manual statistics using recursion
* ⚙️ Functional programming (filter, map, reduce)
* 🔢 Bitwise encoding of species
* 🧩 Unique data analysis using sets
* 📄 Automated report generation

---

## 📂 Project Structure

```
├── iris.py
├── iris.csv

```

## ⚙️ Requirements

* Python 3.x
* Pandas

Install dependency:

```bash
pip install pandas
```

## ▶️ How to Run

1. Place `iris.csv` in the project folder
2. Run the script:

```bash
python iris.py
```

3. Output:

* Report displayed in terminal
* Report saved as a `.txt` file
